## 3. 高频好评（≥12/20 人）

1. **D3→D4 同一梗变刀**（17 人）— 最强记忆点；「记性不好」从耍赖变真忘。

3. **十日体量**（14 人）— 单次 25–40 分钟、通勤分天、直播一条线，长度合适。  
4. **D10 双向遗忘收网**（13 人）— 差异化卖点；含毒舌型样本认可。  
5. **地图动线 + 「又一次归来」院子**（12 人）— 主街、旧田、空土垄叙事级。  
6. **无 API 可通关**（11 人）— 对发行重要。  
7. **Bad / BadEarly 为完整写作**（10 人）— 非数值惩罚屏。

## 6. 信任链（专项 · 最高优先级）

> **14/20 人**在 D4 第一反应「存档坏了 / bug」——产品级信任事故，优先于 C6 差分、Web 导出。  
> 任务 ID：**T10-E2**（D4 防误判）· **T10-E5**（stranger OOC）  
> 主要代码/文案：`config/story_nodes.json`（`t10_d4_telegraph` / `d4_amnesia_hint`）· `scripts/ui/main_ui.gd` · `scripts/ui/day_cycle_overlay.gd` · `tools/local_llm_server.py`（双端同步）

### 6.1 定义：信任链是什么

玩家需始终相信：

1. **她会忘** — 是设定，不是故障  
2. **存档还在** — 名字、约定、本子条目未丢  
3. **LLM 没出戏** — stranger 期不亲昵、不「又见面了」  
4. **D10「你也会忘」** — 是收网，不是强行反转  

任一段断裂，D4 变 bug 疑云，D8/D10 双向遗忘失去重量。

### 6.2 五段链条与当前缺口

| 阶段 | 目标 | 现状 |
|------|------|------|
| **D1–D3 预埋** | 玩家有「她会忘」心理模型 | D3 有「记性不好」，缺半句「哪天连名字也会糊掉」 |
| **D4 晨** | 打击前完成「不是存档坏了」框架 | telegraph 文案**已有**，但塞在 `P_N05` 信纸「清晨」步，**易连点滑过** |
| **D4 节点** | 「你是谁」演出档位 ≥ 文学档位 | 无 BGM stinger / 画面变调；toast hint **仅玩家主动问身份**才出 |
| **D4–D5 行为** | stranger 口径一致 | `ResponseValidator` + fallback 部分有；断网问「bug」无专用句 |
| **全程可验证** | 技术型玩家能证存档未坏 | 记忆面板有数据，但**无引导**「字还在，变的是她认不认得你」 |

### 6.3 已落地（保留 · 勿重复造轮子）

- `morning.t10_d4_telegraph`：含「这不是存档坏了——是她的记忆真的空了一截」。  
- `system.d4_amnesia_hint`：「……这是她的失忆。不是存档坏了。」（`main_ui._maybe_show_d4_amnesia_hint`）。  
- `story_route_data.should_inject_morning_opening`：`P_N05` 强制注入清晨。  
- blocking 已叙事化：`blocking_story_beat` / `blocking_story_finale` 等。  
- `story_test_runner`：断言 telegraph 含「不是存档」或「失忆」。

**问题不在「没写」，而在出现太晚、太弱、太被动**（3s toast + 可跳过信纸页）。

### 6.4 改进建议 · P0

| # | 建议 | 做法 | 验收 | 文件 |
|---|------|------|------|------|
| T1 | **D4 清晨不可跳过** | 过天到 D4：`day_cycle_overlay` 在「第 4 天」卡后**单独半屏信纸**只放 telegraph；须点「知道了」再进场景（或 telegraph 独立 step + 禁连点跳过） | 纯节点流、不聊天，试玩不问 bug | `day_cycle_overlay.gd` · `main_ui.gd` |
| T2 | **`P_N05` 结束固定 hint** | beat 播完自动 `_system_hint("d4_amnesia_hint")` 或小狸旁白一句；用 `d4_amnesia_hint_shown` 防重复；**不依赖**玩家提问 | 不看聊天也收到一次 | `main_ui.gd` · beat finished 钩子 |
| T3 | **D3 结尾预埋** | `P_N11` 加半句：「说不定哪天连你的名字也会糊掉……到那天，你还得再教我一遍。」 | D4 反应从 bug 疑云变为「她说过会这样」 | `story_nodes.json` |
| T4 | **记忆面板首次证存档** | D4 首次打开记忆面板：「本子上的字还在。变的是她认不认得你。」`d4_memory_panel_hint_shown` | 技术型玩家自证存档 | `memory_panel.gd` · `main_ui.gd` |
| T5 | **stranger 统一口径** | LLM prompt + `npc_fallback`：玩家问「bug/存档坏了」→「不是坏了。是我这边又空了一截。」；禁「欢迎回来」「又见面了」（**T10-E5**） | 有/无 API 口径一致 | `local_llm_server.py` 双端 · `npc_fallback.gd` |

|---|------|------|

### 6.6 改进建议 · P2

- D2 她随口：「雨会把东西冲掉，字也是。」（远期伏笔）  
- itch FAQ 一条：「小狸会忘记你，是设定，不是存档错误。」  

### 6.7 禁止做法（伤信任）

- ❌ 弹窗「系统提示：进入陌生化章节」  
- ❌ 小狸台词点破「游戏机制 / 存档」（D10 awaken 前）  
- ❌ 用亲密度/数值解释「为什么忘」  
- ❌ stranger 期 LLM 仍亲昵（比无 hint 更毁信任）

### 6.8 验收清单

| 测试 | 通过标准 |
|------|----------|
| 纯节点流 | 不聊天、不开面板，D4 后不说「存档坏了」 |
| 技术型 | 开记忆面板见名字/约定仍在 |
| 聊天型 | 问「你是谁」得叙事答复，非 generic |
| 断网 | 与有 API 口径一致 |
| 自动化 | 保留 telegraph 断言；可加「P_N05 结束 hint 触发」 |

**一句话**：在玩家起疑**之前**用流程硬步骤订成规则；起疑**之后**用面板 + 固定口径证明存档没坏。

## 7. 交互体验（专项）

> 二十人中 **13 人**提聊天 UI 挡路、**11 人**提 blocking 语气；设计对齐见 `docs/UI设计稿_十日版.md`。  
> 主要代码：`scripts/ui/main_ui.gd` · `scripts/world/farm_world.gd`（陪坐）· `scripts/autoload/companion_agent.gd`（主动靠近）

### 7.1 现状 · 已做得不错

- 多数 blocking 已是叙事口吻：「她今天还有话要说，再等等」「她好像还有话想说」「天还亮着，再等等」。
- D10 锁田：「今天……她好像有很重要的话要说。田先放一放。」（`main_ui._blocks_farm_chores`）。
- 移动时聊天自动失焦，WASD 不与输入框抢键（`main_ui._on_chat_input_gui_input`）。
- 主动靠近 + 追跑 toast + 傍晚二次邀请（T10-G4/G5）已接线。

### 7.2 现状 · 仍偏系统 / 未落地设计稿

| 类别 | 现状 | 玩家反馈 |

### 7.4 仍偏系统的 hint 句（T10-E1 待改文案）

`main_ui.gd` 中建议优先改写：

- `没有萝卜种子了。` → 小狸口吻或篮子入口引导

## 8. 声画与 BGM（专项）

> 二十人中 **仅 #17（声画氛围）、#20（深夜 emo）** 重点评 BGM；#2 种田党几乎不关心。  
> 主要代码：`scripts/autoload/bgm_director.gd` · `scripts/world/rain_world.gd`（仅视觉雨，无音频）

### 8.1 现状

| 项 | 现状 |
|----|------|
| BGM | 仅 2 轨：`白天bgm.mp3` / `夜晚bgm.mp3`；日/夜 0.8s 交叉淡入淡出 |
| 标题页 | 固定播白天轨 |
| 睡觉 | `stop_for_sleep()` → 过天 → `resume_day_after_sleep()` **一律恢复白天轨** |
| 音效 | **全项目无 SFX 文件** |
| 雨天 | `rain_world.gd` 画线 + `rain_splash.gd` 溅点；**无雨声、无 BGM 变奏** |
| 叙事 stinger | D4 / D7 / D10 无专用短乐句 |

**高分点（#17）**：D2 强制雨 + 日/夜 BGM 切换 + 睡觉渐黑停 BGM。  
**扣分点**：D6–D8「演出偏静」；D10 觉醒若 skip 则声画高潮断档；Web 未测浏览器 autoplay 拦截。

### 8.2 声画 / BGM 改进建议

| 优先级 | 建议 | 做法概要 | 主要文件 |
|--------|------|----------|----------|
| **P1** | **D2 雨天环境音** | 雨声 loop（低音量）；进廊下 `is_rain_sheltered` 时衰减 | 新建 `AudioStreamPlayer` + `farm_world.is_rain_sheltered` |

### 8.4 最高 ROI 三件（交互 + 声画 + 信任）

1. **§6 信任链 T1–T3**（D4 不可跳过 telegraph + P_N05 结束 hint + D3 预埋）  
2. **话区按 UI 设计稿改一版**（§7.3）  
3. **D2 雨环境音 + D4 stinger**（§8.2）
