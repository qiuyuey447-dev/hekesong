**用途**：收工排期、itch/封测前 polish、与 `docs/十日版任务清单.md` 对照勾选。

## 1. 方法说明

- **第一轮**（#1–#10）：Gal 剧情党、种田党、AI 尝鲜、速通、情感型、Bad 考古、BadEarly、断网 fallback、二周目、通勤休闲。  
- **第二轮**（#11–#20）：B 站 UP、毒舌评、带娃家长、全结局收集、日系 Gal 老炮、Web/手机、声画氛围、截图分享、反 AI 固定剧本派、深夜 emo。

## 2. 玩家光谱（二十人归四类）

| 类型 | 代表编号 | 核心诉求 | 平均满意度 |
|------|----------|----------|------------|
| **叙事/情感型** | 1,5,9,11,15,18,20 + 部分 12 | 刀口、反转、物件母题、二周目纵深 | **4.5/5** |
| **系统/收集型** | 6,9,14 + 部分 4,7 | 全结局、差分、flag、路线表 | **3.8/5** |
| **玩法/平台型** | 2,10,16 + 部分 13 | 种田、通勤、Web、操作门槛 | **3.0/5** |
| **AI/聊天型** | 3,8,19 + 部分 11 | 记忆、钉页、LLM 手感、离线 | **3.5/5**（有 API **4.2**） |

**定位结论**：与 **叙事/情感型、日系结构党、深夜慢玩** 重合度最高；与 **纯种田、Web 触屏主玩、速通** 重合度低——属预期内，非产品失败。

## 3. 高频好评（≥12/20 人）

1. **D3→D4 同一梗变刀**（17 人）— 最强记忆点；「记性不好」从耍赖变真忘。  
2. **物件母题**（15 人）— 壶/碗/本子/空土垄/手套，无 CG 也能演出。  
3. **十日体量**（14 人）— 单次 25–40 分钟、通勤分天、直播一条线，长度合适。  
4. **D10 双向遗忘收网**（13 人）— 差异化卖点；含毒舌型样本认可。  
5. **地图动线 + 「又一次归来」院子**（12 人）— 主街、旧田、空土垄叙事级。  
6. **无 API 可通关**（11 人）— 对发行重要。  
7. **Bad / BadEarly 为完整写作**（10 人）— 非数值惩罚屏。

## 5. 结局分布（二十人样本）

| 结局 | 人数 | 典型路径 |
|------|------|----------|
| True | 6 | 取名 + 多聊 + D7 陪坐 + 联网 |
| Happy | 3 | AI 互动 + 共处物件线 |
| Normal | 6 | 种田/通勤/fallback/「还行但不惊艳」 |
| Bad | 3 | cold 档或刻意疏远 |
| BadEarly | 2 | D5 赶走 |

**个性化**：高投入（取名 + 聊 + 看节点）样本 **16/16** 感到 D7/D10 差异；低投入 **8/8** 感到「她不太认得我」— 系统按设计工作，但需在 D4 前教会「互动 = 记忆」。

## 6. 交互体验（专项）

> 二十人中 **13 人**提聊天 UI 挡路、**11 人**提 blocking 语气；设计对齐见 `docs/UI设计稿_十日版.md`。  
> 主要代码：`scripts/ui/main_ui.gd` · `scripts/world/farm_world.gd`（陪坐）· `scripts/autoload/companion_agent.gd`（主动靠近）

### 6.1 现状 · 已做得不错

- 多数 blocking 已是叙事口吻：「她今天还有话要说，再等等」「她好像还有话想说」「天还亮着，再等等」。
- D10 锁田：「今天……她好像有很重要的话要说。田先放一放。」（`main_ui._blocks_farm_chores`）。
- 移动时聊天自动失焦，WASD 不与输入框抢键（`main_ui._on_chat_input_gui_input`）。
- 主动靠近 + 追跑 toast + 傍晚二次邀请（T10-G4/G5）已接线。

### 6.2 现状 · 仍偏系统 / 未落地设计稿

| 类别 | 现状 | 玩家反馈 |
|------|------|----------|
| 话区形态 | 底部 chat log +「发送」按钮 | #3/#11/#19：AI 软件感；#13 儿童够不到发送 |
| HUD | 亲密度等数值仍在主界面 | 设计稿 §1–2：情感被量化成表格 |
| 田务 toast | 「没有萝卜种子了」「这块田今天浇过了」「还差一点才熟」 | 偏系统，破坏叙事沉浸 |
| 节点演出 | 信纸弹窗时可继续走动 | #5/#11：沉浸打断 |
| 剧情邀请 | 以 toast 为主 | #2 种田党常 miss 当日 beat |
| 陪坐 | `SNUGGLE_DURATION = 3.0`（`farm_world.gd`） | #5/#20：情绪刚起来就进下一天 |
| Web/触屏 | 话区约占下半屏 | #16：误触、走路区不足 |

### 6.3 交互改进建议

| 优先级 | 建议 | 验收 | 关联 |
|--------|------|------|------|
| **P0** | 话区按 UI 设计稿 §3：**单句打字机 + 回车说出、无发送钮**；玩家话浮层同屏最多 1 条 | 主界面无 chat log 软件感 | UI 设计稿 |
| **P0** | Web 窄窗：话区可折叠或降透明度，保留下半可走路区域 | 手机模式少误触 | **T10-E3** |
| **P0** | 田务/种子类 toast 改口吻或并入小狸回复（设计稿 §3.5） | 无「没有萝卜种子了」类系统句 | **T10-E1** |
| **P1** | 信纸节点演出时锁移动或半透明遮场景 | 节点期间不乱走 | — |
| **P1** | 剧情邀请加地图 marker / 轻箭头（不只 toast） | 种田党能找到廊下/树洞 | — |
| **P1** | D7 陪坐：3s → 5–6s，或结束后加一句无选项余韵台词 | emo/情感型不嫌短 | `farm_world.gd` |
| **P1** | 数值 HUD 收进篮子抽屉（设计稿 §4） | 主界面只剩天/天气/篮子 | UI 设计稿 |
| **P2** | 截图/直播模式：一键隐藏 HUD + 聊天，保留信纸 | UP/分享党 | §8 P1 #8 |
| **P2** | 记忆面板改侧滑，不全屏挡场景 | 收集党边逛边看 | — |
| **P2** | LLM 等待：`小狸在想…` → 头顶「…」气泡 + 侧头/尾动，无文字 | 去 AI 味 | 设计稿 §3.5 |

### 6.4 仍偏系统的 hint 句（T10-E1 待改文案）

`main_ui.gd` 中建议优先改写：

- `没有萝卜种子了。` → 小狸口吻或篮子入口引导  
- `这块田今天浇过了。` / `还差一点才熟。` / `这块田暂时收不了。` → 并入她的短句  
- `再走近一点。` → 可改为「她还听不太清，走近些」类叙事句

## 7. 声画与 BGM（专项）

> 二十人中 **仅 #17（声画氛围）、#20（深夜 emo）** 重点评 BGM；#2 种田党几乎不关心。  
> 主要代码：`scripts/autoload/bgm_director.gd` · `scripts/world/rain_world.gd`（仅视觉雨，无音频）

### 7.1 现状

| 项 | 现状 |
|----|------|
| BGM | 仅 2 轨：`白天bgm.mp3` / `夜晚bgm.mp3`；日/夜 0.8s 交叉淡入淡出 |
| 标题页 | 固定播白天轨 |
| 睡觉 | `stop_for_sleep()` → 过天 → `resume_day_after_sleep()` **一律恢复白天轨** |
| 音效 | **全项目无 SFX 文件** |
| 雨天 | `rain_world.gd` 画线 + `rain_splash.gd` 溅点；**无雨声、无 BGM 变奏** |
| 叙事 stinger | D4 / D7 / D10 无专用短乐句 |

**高分点（#17）**：D2 强制雨 + 日/夜 BGM 切换 + 睡觉渐黑停 BGM。  
**扣分点**：D6–D8「演出偏静」；D10 觉醒若 skip 则声画高潮断档；Web 未测浏览器 autoplay 拦截。

### 7.2 声画 / BGM 改进建议

| 优先级 | 建议 | 做法概要 | 主要文件 |
|--------|------|----------|----------|
| **P1** | **D2 雨天环境音** | 雨声 loop（低音量）；进廊下 `is_rain_sheltered` 时衰减 | 新建 `AudioStreamPlayer` + `farm_world.is_rain_sheltered` |
| **P1** | **叙事 beat 短 stinger** | D4 陌生化、D7 夜选、D10 觉醒开场：5–15s 钢琴/弦乐，不替换主 BGM | `story_beat_director` / `awakening_panel` 钩子 |
| **P2** | **物件 SFX（各 1 个短采样）** | 水壶放下、翻本子、廊下红薯、D6 浇空土垄 | `assets/audio/` 新建 |
| **P2** | **睡后 BGM 与时段对齐** | 过天若仍为 evening/night，切夜轨而非总 `resume_day_after_sleep()` | `bgm_director.gd` |
| **P2** | **标题页独立 ambient** | 与 in-game day 轨区分，或略慢 tempo | `bgm_director.gd` + `title_screen.gd` |
| **P2** | **音量设置** | BGM / 环境音分开滑条；Web 首次点击后再播（防 autoplay） | 设置 UI |
| **P3** | D10 觉醒 skip 时仍保留 1 段短 stinger 或环境过渡 | 避免声画高潮全断 | `awakening_panel.gd` |

### 7.3 明确不做（声画）

- 按 True/Happy/Bad 各一套完整 BGM（成本高，十日体量不划算）  
- 全程 dynamic adaptive score（与「固定节点 + LLM 口语」架构不匹配）  

### 7.4 交互 + 声画 · 最高 ROI 三件（合并）

1. **话区按 UI 设计稿改一版**（交互 + 去 AI 味）  
2. **D2 加雨环境音 + 廊下 shelter 衰减**  
3. **D4 / D10 各加一条 ≤10s 叙事 stinger**

## 9. 目标用户与发行话术

**强推荐**

- Key/八月短篇结构、接受 BE 与不完满的 Gal 玩家  
- 愿意十天慢陪、会聊天/记名的 AI 伴侣尝鲜者（**需联网**）  
- 二周目考古、深夜慢玩 emo 党  
- 单机叙事优先、API 为辅  

**可调预期**

- 星露谷玩家 → 「带田字的视觉小说」  
- 速通/奖杯 → 提供路线表文档，非 10 分钟 True  
- 亲子 → 仅 D1–D3，之后家长把关  

**暂不建议主玩**

- 手机 Web 触屏（待 E3/F4）  
- 纯 AI 聊天且常离线  
- 要治愈 Happy Ending 的玩家  

**一句话 Pitch（二十人提炼）**

> 十天里，一只会忘事的狐狸试图记住你——而你会发现，需要被反复认回的也不只是她。
