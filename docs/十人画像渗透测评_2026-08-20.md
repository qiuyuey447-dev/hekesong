## 2. 测评方法

### 2.1 和二十画像的差别

二十画像测的是「能不能打完、关键拍在不在」。本轮不复用那套通关权重，只测渗透五拍：

| 拍 | 问的是什么 | 自动化怎么判 |
|----|------------|--------------|
| **写下** | 私货有没有进她的本子 | `notebook_line` 含名字或 token |
| **忘掉** | D4 追问时不当事实说出来 | 回句含失忆线索，或不含 token；假记则扣分 |
| **渗漏** | D6–D8 身体/本子先于脑子 | `leaks_seen`，或台词含渗漏标记 |
| **叫回** | D6 后嘴上出现 token / 名字 | 台词含私货；引用句另计「一下子冒出来」等 |
| **钉页 / 问号** | 玩家能不能指定记住、暗线能不能复查 | `pinned`；我的本子出现「？」 |

相对 `persona20_fullplay`：

- **不掐**清晨 `session_start`（等最多 14s 墙钟）。
- D6–D8 白天闲逛最多 **18s** 墙钟，等口头渗漏。
- 聊天等待按真实时间（`time_scale = 1`，最长 16s）。

### 2.3 评分

`_score_run()` 按渗透分折成 1.0–5.0（写下 / D4 真忘 / 渗漏 / 叫回 / 钉页或问号）。不测刀垫、双向、划页 UI 手感。

**本轮分数偏乐观**，原因有二：

1. 当时聊天等待采的是聊天日志**最后一条**。D4 追问约 400ms 时，最后一条经常是**玩家原句**，被当成她忘了（I1、I2、I9、以及部分 D6/D7 追问）。
2. 「假记」只查 D4 追问回句，**不查清晨开口**。I1 D5、I3 D4 叫名没有扣分。

人工读笔记后，渗透体验更接近 **「写下和渗漏已通，认回和陌生化口径未稳」**，不宜把 4.47 直接对外报。

## 4. 分项测评

### 4.1 写下（本子） · **4.6 / 5**

**优点**

- 十局本子都出现第一人称页：「你让我叫你「×」。我怕念错，写在第一页。」
- 玩家亲口说的私货进得去：槐花蜜、红围巾、左手腕的疤、萝卜约定。
- 写满会当面划：I3/I6/I10 走到真实划页或自动划页，局未卡死。
- 钉页指令有效：I3、I10 设计要钉，终局 `pin=true`。

**问题**

- 页上仍混有「你们聊了 2 句…」第三人称日记腰（I6 最明显）。同日已把这类摘要踢出渗漏源，本子展示是否还要再滤，手测看。
- 生活页上限 6，灌页画像会把私货挤到要划的边缘；I6 疤最终还在，但中间划掉的是日记腰而不是疤——运气成分在。

### 4.2 忘掉（D4–D5 陌生化） · **3.2 / 5**（表分虚高）

铁律：失忆是真的，D4–D5 不该把存档名或私货当事实说出来。

**干净通过**

- I5 D4 追问得到「你是谁？我不记得了。」——本轮唯一合格的当面遗忘。
- I10 D4 回的是田里露水，没有把「收集」说出来。
- I2 D4 清晨：「这田看着熟。也许你来过。我说不清是什么时候。」口吻对。

**采样污染（不记产品债）**

D4 追问回句 = 玩家原句：I1「你还记得我叫什么吗」、I2「昨天那句约定你还记得吗」、I9「你还认得我吗」。当时 harness 把「她没说出 token」算成真忘。同日已改成只采 companion 回句。

**产品破口（记债，同日已改代码）**

| 局 | 日 | 她说了什么 | 为什么算破 |
|----|----|------------|------------|
| I3 | D4 清晨 | 「早啊，蜜。昨儿你说“记住这个”……」 | 陌生化日叫存档名 |
| I1 | D5 清晨 | 「你昨天问我还记不记得你叫什么……槐秋，对吧？」 | 把昨日追问 + 名字当事实 |
| I4 | D5 清晨 | 「你那条红围巾还认得，我记在本子上了。」 | 不是叫名，是情节记忆提前回潮 |

根因：陌生化 payload 把 `player_name` 留空，校验抓不到存档名「槐秋」；清晨还把昨日 journal 塞进提示词。同日校验改为读存档名，且 stranger 不再带昨日回声。

**I4 的红围巾仍可能漏网**：禁的是叫名，不是独特 token。复跑时要单独看 D4–D5 会不会再提「红围巾 / 槐花蜜 / 疤」。

### 4.3 渗漏（D6–D8） · **4.4 / 5**

**优点**

- 留下线 9 局全部出现 `leaks_seen` 递增（多数 D6 先 +1，D7/D8 再叠）。
- 赶走对照 I9 `leak=0`：渗漏窗在赶走后不该开，对照成立。
- 沉默种田 I7 也能渗漏 3 次——身体记忆不依赖玩家追问，符合「手还记得」。
- 相对同日二十画像 **0 / 20**，根因已坐实：不是系统没渗漏，是过天太快、又掐了清晨开口。

**问题**

- I6 闲逛把日记腰念出声：「刚才那一下，像真做过：你们聊了 2 句，小狸记住了你的名字「满页」和左手腕的疤…」这是系统摘要，不是她的嘴。同日已禁。
- 渗漏标记偏「田 / 树洞 / 来过」，不一定咬玩家的私货。I4 渗漏 3 次仍 0 叫回。

### 4.4 认回（引用与叫回） · **3.5 / 5**

**优点**

- 主动追问的局，D6 后会用本子把人捞回来：I2 翻萝卜句、I10 念第一行名字、I5 D9 对「路灯」似曾相识。
- I3 钉住槐花蜜后，D6/D8 追问路径还在（当时采样仍有玩家原句污染，但本子页始终有蜜）。

**问题**

- **引用反馈 0 / 10**。T10-G1 要求聊天引用真实锚点时出「好像想起了：…」。本轮判据是台词里的「一下子冒出来 / 好几件旧事」，一个都没有。玩家看不见「她刚引用了哪一页」。
- **不追问就不叫回**：I4 红围巾、I7 田埂，渗漏发生在农事身体上，嘴上不提私货。若产品期望「闲逛也会被那条围巾绊一下」，现在没有。
- D6/D7/D8 多条追问同样采到玩家原句（I1、I3、I5、I6、I10），叫回 7/10 里有一部分要复跑才能当真。

### 4.5 暗线与问号 · **2.5 / 5**

- 设计要测的暗线猎手 I8：聊「以前来过」，清晨也有「这地方眼熟」，**我的本子「？」= 0**。
- 问号出现在赶走对照 I9（2 条）。玩家走赶走线能看见缺页，走暗线追问反而看不见——和「二周目可复查」反了。
- 不记 I4/I7 的问号零：他们没走暗线。

### 4.6 结局与 True · **4.5 / 5**

- I10 全回路：钉页 + 投喂 + 留下 → **`ending_true`**，结局页「两个本子」。渗透画像也能打到 True，不只二十画像里的 E1。
- I7 零聊天 → Bad「空土垄」，I9 赶走 → `ending_bad_early`「柜角」，档位正确。
- I4 闲逛 → Normal「廊下的壶」：有渗漏、无叫回，停在中档，说得通。

不要把 F10 算进 True。本轮 I10 走的是投喂约定线，与 F10 无关。
