# 《河可松》十日版 UI 设计稿 · 重对话 · 去 AI 味

> 定位：把界面从「和 AI 聊天的农场管理器」改成「一个人在你面前对你说话的暖场景」。
> 原则：**重对话、轻游戏**；删掉一切让人想起「我在用软件跟 AI 对话」的外壳。

## 1. 现状诊断（为什么「有 AI 味 + 重游戏」）

- 底部是**聊天软件式文字 log**：`你：`（蓝 #9fd3ff）/ `小狸：`（橙 #ffd59a）名字前缀、`发送`按钮、`小狸在想…/在理解你的意思…` loading 文案、`（+2 认真回应）`/`（本地 mock · 非大模型）` 系统副作用直接打进对话——AI 味最大来源。
- HUD 一排数字：金币/种子/萝卜/亲密度/默契/心情/互动%/片段数——情感被量化成表格 = 重游戏。

---

## 2. 信息层级（收敛后）

主界面只留三层，其余全部下沉：

1. **她和你的话**（唯一主角，占视觉 60%+）
2. **极简状态**：第 X 天 / 共 10 天 · 天气 · 时段（左上，弱）
3. **篮子入口**（右上圆钮，收纳所有玩法与数值）

撤出主界面：亲密度/默契/心情/互动%/片段数、系统副作用文案、`发送`按钮、名字前缀。

## 3. 主界面布局

基准 1152×648，等比缩放。

### 3.1 顶部安全区（高 56px）
- 左上状态串：`第 3 天 · 共 10 天  ☀ 傍晚`，14px `#8A6E4F`，透明度 70%。
- 右上篮子圆钮：48×48。右下角一个很小的数字气泡 = 金币（keep_econ）。不显示种子。

### 3.2 中部
- 留给场景与小狸，**不放任何控件**。

### 3.3 底部话区（高约 34% 屏高，顶边 48px 羽化渐隐，无边框无圆角）
从上到下：
- **玩家话浮层**（右对齐）：16px `#8C7B68` 低对比；出现→停留 1.8s→上浮 12px 同时淡出 0.4s；**同屏最多 1 条**，新话覆盖旧话。
- **小狸落款** `小狸`：14px `#8A6E4F`，左对齐，带 18px 小藤蔓分隔纹。
- **小狸正文**：**21px** `#3D3329`，行高 1.55，左对齐，**打字机 ~14 字/秒**；点击/空格瞬显。
- **继续箭头**：右下 `↘`，呼吸动画（0.9s 一次，上下 3px）。

### 3.4 输入行（贴底 40px）
- 1px 底线 `#B8946B @30%`；占位 `…（轻声对小狸说）` 14px `#A79684`。
- 聚焦：底线提亮到 60% + 左侧羽毛笔小图标亮起；**回车说出，无按钮**。
- 移动中（WASD）：输入自动失焦、占位变灰，键位回落给移动（沿用现逻辑）。

### 3.5 去 AI 味的替换
- `小狸在想…` → 她头顶 `…` 小气泡 + 侧头/尾巴微动，无文字。
- 浇水/收获等系统结果 → 并入她的口吻：`田我都替你浇好啦，泥土香香的。`
- delta / 引用 / mock 等 → 全部移入 Debug 面板（保留原调试开关）。

## 4. 篮子抽屉（keep_econ）

主界面角标极简（金币小气泡）。点击篮子 → 右侧滑出半透明暖底抽屉：
- **过日子**：金币 · 萝卜 · 种子（图标 + 数字，纯信息）
- **入口**：商店 / 大盘 / 记忆（三枚暖色小钮）
- **她**：关系小苗（见 §5）+ 一句关系状态词

抽屉打开时世界不暂停但话区下沉——强调「随手翻开的口袋」，不是菜单。

## 5. 关系成长隐喻（metaphor）〔待确认：小苗 vs 灯，推荐小苗〕

主角是萝卜田，用一株小苗最贴题（也呼应「两个本子 / 慢慢记住」）：

| 阶段（原亲密度段） | 小苗视觉 | 关系状态词 |
|---|---|---|
| 初识 stranger / 低 | 一粒埋在土里的种子，土面微鼓 | 还在熟悉 |
| 友好 | 冒出两片子叶 | 慢慢亲近 |
| 亲密 | 抽高、三四片叶 | 处得像家人 |
| 羁绊 / 高 | 顶端一朵小花 / 结出小萝卜 | 心照不宣 |

- **放置**：篮子抽屉「她」区；每天清晨开场用一句她的话侧写当前阶段（不给条、不给数字）。
- **反馈**：阶段跨越时小苗「长一节」轻动画（600ms ease-out）+ 她一句应景的话，代替 `+2` 数字。
- **彩蛋**：D8「两个本子」揭示时，小苗旁多一株——**两株并排**，呼应双向遗忘。

## 6. 剧情 / 结局信纸时刻

- 纸卡：`#F7F0E6` 纸底 + 淡横线 `#00000008` + 毛边；宽约 62% 屏宽，居中；世界**不变黑**，仅轻微压暗。
- 正文：居中，18–20px `#473826`，**打字机**，段间大留白；情绪高潮句可放到 26px + 独占一屏。
- 选项：2–3 张**便签**（`#FAF0D8`，纸胶带贴角，轻微旋转 ±2°），hover 上浮 4px。
- 计数 `2 / 4` 缩到纸右下角，14px 30% 透明。
- 觉醒 / 结局复用同一套纸语言，仅底色更暗、留白更多。
