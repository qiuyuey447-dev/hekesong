## 设计规则（备忘）

> **约定**：凡涉及玩法边界、记忆分层、LLM 职责划分等**规则类改动**，在本节追加条目，并在「会话记录」留实现索引。

### XL-C6 · 日末 `day_journal`（规则底座 + LLM 聊天摘要）

**目标**：journal 必须反映玩家与小狸的聊天，支撑次日个性化小狸；同时避免记忆膨胀。

**分层职责**

| 层 | 时机 | 来源 | 写入位置 |
|----|------|------|----------|
| L1 规则底座 | 同步（入睡瞬间） | 当日 `short_term_memory` 事件 | `day_journal.summary` / `highlights` / `tags` / `facts` |
| L2 聊天摘要 | 异步（API 返回后 patch） | 当日 `today_chat_log` → LLM `day_journal_summarize` | `day_journal.chat_summary` / `companion_feel` |

**聊天采集**

- `GameState.record_chat_turn()` 双写：`recent_chat_turns`（对话上下文，cap 12）+ `today_chat_log`（日末专用，**cap 16**）
- `advance_day()`：先 snapshot `today_chat_log`，再 `clear_today_chat_log()`；**聊天原文不进入长期层**

**LLM 事件 `day_journal_summarize`**

- 输入：`journal_entry`（规则底座）+ `today_chat_log`（最多 12 轮送 LLM）
- 输出 JSON：`chat_summary`（≤120 字）· `companion_feel`（≤80 字，可空）· `salience`（0~1）
- 结果 patch 到对应 `day` 的 journal；替换规则版「聊天 · …」highlight，避免重复
- **不进聊天 UI**（`main_ui` 对应该事件 early return）

**防膨胀**

| 规则 | 值 / 行为 |
|------|-----------|
| 当日聊天轮次上限 | `MAX_TODAY_CHAT = 16` |
| journal 保留天数 | 7 天（`append_day_journal` 滑动窗口） |
| 长期层内容 | 仅 `chat_summary` 语义摘要，**禁止**聊天原文 |
| `journal_chat` anchor | 仅当 `salience ≥ 0.72` 且 **非 W2 stranger**；**每个 game_day 最多 1 条** |
| 普通 `chat` 事件 | 仍进 `short_term_memory`（cap 12），高 importance 可走通用 anchor 逻辑 |

**Fallback（无 LLM / stranger / API 失败）**

- 规则 `_rule_chat_digest`：取玩家末句或句数统计，写入 `chat_digest_rule` / `chat_summary`
- fallback 时 `salience = 0.55`，**不写** `journal_chat` anchor

**相关文件**

- `scripts/autoload/day_journal_service.gd` · `game_state.gd` · `npc_bridge.gd`
- `tools/local_llm_server.py`（`day_journal_summarize` prompt）
- `scripts/ui/main_ui.gd`（UI 隔离）

### XL-C6b · 本地 fallback 边界 + LLM 剧情上下文

**本地判定（NpcFallback / estimate_local_delta / demo_script）**

- **仅当** `NpcBridge.is_api_enabled() == false`（未配置/未连接 API）时使用
- `demo_script.get_event_override()` **不再**在 API 已连接时短路 LLM（曾导致 week≥3 +「记得」硬编码台词 +「本地判定」提示）
- API 已连接时：HTTP 失败、校验拦截、空回复 → 返回通用短句（`LLM_FAILURE_REPLY`），**不**降级为 `NpcFallback` 脚本台词
- 亲密度：`RelationshipDirector.estimate_local_delta()` 仅在 offline（`used_fallback` 或未接 API）时补算
- `local_llm_server.py --llm` 模式：LLM 调用失败返回 **503**，不再 server 端 mock 降级

**LLM 剧情上下文 `story_context`**

- `StoryDirector.get_story_context_for_llm()`：周目 hint/goal、路线、待触发节点、近期 story_beat、叙事边界
- `NpcBridge` payload 新增 `story_context`；Prompt 首段 `[必达剧情背景 — 回复不得与此矛盾]`
- 闲聊也须遵守 story_mode（修复原先 general 话题隐藏 hint 导致 OOC）

**相关文件**

- `story_director.gd` · `npc_bridge.gd` · `main_ui.gd` · `local_llm_server.py`
