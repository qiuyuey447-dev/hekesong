## 2. 叙事 / 剧情系统

### 2.1 主线节拍：时段门控与「尾巴续播」

**文件**：`scripts/autoload/story_beat_director.gd`、`scripts/autoload/story_route_data.gd`、`scripts/autoload/game_state.gd`

**做什么**：

- 信纸步骤支持 `period_gate`（例如仅 `evening` / `night` 才出现的选项）。
- 白天打开某 beat 时，带 `period_gate` 的后半段步骤会**暂存**到存档（`pending_story_beat_tail_id` / `pending_story_beat_tail_steps`）。

**为什么**：十日版部分选择只能在夜里发生；白天误触不应把整段 beat 标为已读。

## 3. LLM / 意图识别

### 3.1 「查田况」与「睡觉」分流

**文件**：`scripts/autoload/intent_parser.gd`、`tools/local_llm_server.py`、`cloudrun/xiaoli-api/tools/local_llm_server.py`（双端同步）

**做什么**：

- 新增 `looks_like_status_inquiry()`：「熟了没」「田怎么样」「能收了吗」等。
- `looks_like_sleep_request()` 遇到查田况时 **不再** 判为睡觉。
- LLM mock / `apply_local_intent`：查田况强制 `intent=check_status`；若 reply 只有催睡、没有田况则剥掉 reply。
- `npc_bridge` player_chat 指令补充：问田况时禁止误 sleep。

**UI 侧清洗**（`main_ui.gd`）：

- `_sanitize_unrequested_sleep_push()`：玩家问熟没，LLM 却催睡觉 → 去掉纯睡话段落。

### 3.2 「别种 / 别浇 / 别收 / 别买」拒绝农活

**文件**：

- `scripts/shop/shop_delegate.gd` — 大量 `looks_like_*_declined()` / `looks_like_chore_declined()`
- `scripts/autoload/intent_parser.gd` — `looks_like_stop_farm_chore()`、`stop_chore` 匹配
- `tools/local_llm_server.py` + cloudrun 镜像 — 同上 + `guess_intent` 返回 chat
- `scripts/ui/main_ui.gd` — `_try_cancel_active_chore_from_chat()` 取消进行中的代劳

**做什么**：

- 玩家说「别浇了」「雨停再种」「不用买了」等 → **不** 触发 plant/water/shop action。
- 否定回复也纳入 `is_negative_reply()`。
- 各类「承诺 / 已完成」检测前先排除 declined，避免 LLM 幻觉触发买种/浇完。

### 3.3 意图分类 API 收紧

**文件**：`scripts/autoload/intent_bridge.gd`、`scripts/autoload/intent_parser.gd`

**做什么**：

- `from_api_classify_response()` 专门解析 `/classify` 返回（不再混用 chat reply 解析）。
- `merge_intents(..., classified_by_api)`：API 明确返回 `chat` 时尊重 chat；API 失败 + 本地像指令 → 降级 chat（`classify_failed`），避免误执行。
- `should_fallback()` 改用 `looks_like_ambiguous_command()`，去掉宽泛关键词表（「状态」「帮忙」等一律不再强制走 API）。
- classify 系统 prompt：**讨论** 浇田/商店必须是 chat；**明确委托** 才是 action。
