## 0.5 叙事内核（动骨重构 · 权威设定）

> **本节为最高优先叙事约束。** 与前文任何「治愈/她终于记住你」的旧表述冲突时，以本节为准。

### 0.5.1 互为镜子（双向遗忘）

- 玩家「我」独居守着河边一处偏僻的农场（河可松 =「河边，可以松一口气的地方」），把日子过得很淡——**怕失去，所以不敢拥有、不敢许诺**。
- 一个暮色里，会周期性失忆的狐狸**小狸**走了很远来到田埂求收留。我收留她，起初只当「多个帮手」，刻意不往心里放。
- 「她又把我当陌生人」这一刀先砸中小狸；但更深一层的暗线是——**忘的从来不只是她。**「我」也在这个循环里，轮与轮之间同样会重置、忘光；我全程的「似曾相识」是自己前几轮漏出来的记忆。此真相 **D10 才收网**，此前只以暗线埋（眼熟到心里发紧、「这凉意我好像也尝过」、说不清农场荒了多久）。
- **铁律**：① 不引入第三个人物（无阿嬷 / 病房 / 逝去伙伴）；② 小狸的失忆与「重新学你」必须是**真的**，严禁写成「其实一直记得、只是装忘」（那会摧毁个性化）。

### 0.5.2 最后一个轮回

- 小狸**不是第一次**来这片田。多年来她来了又走、忘了又回。
- 玩家所玩的这十天，是她**彻底消散/离开前的「最后一个轮回」**。
- D1 基调不是「从零初遇」，而是**「又一次归来」**——她自己不记得，但田/物件/我心里的「似曾相识」**是真有来由的**。
- D6 的「这片田我好像浇过水」从**错觉**升级为**真的浇过**（前几轮留下的真实痕迹）。
- 母题（本子×2、名字、雨、水壶、反复描粗的「不能弄丢这里」）都要能被读成**「跨越多轮的重复」**，强化「十天里其实过了很多轮回」的纵深。

### 0.5.3 永不痊愈（主题落点）

> **我们都会忘。可我们总能，从一片空白里，重新把对方找回来。**

- 结局**没有治愈**。**谁都好不了**——不只是她，也包括「我」。玩家陪的是彼此的**「最后一程」**。
- True/Happy 不是「治好谁」，而是**在会忘的前提下，仍替彼此留下能重新找回对方的锚 / 好好爱了这一程**（D10 两个本子并排、为下一轮留路）。
- Bad/BadEarly 是「这一轮没能留住 / 亲手斩断了那个、一轮轮把你们重新牵到一起的方向」。

### 0.5.4 母题清单

| 母题 | 承载 | 跨轮读法 |
|------|------|----------|
| 本子 ×2 | 小狸的本子（不能弄丢这里）+ 我偷偷记满了她的本子 | 日期跨越远不止十天；两个本子互文，D10 揭示忘的也有我 |
| 名字 | 给小狸重新取名 / 她重新唤回我的名字 | 每一轮都要重新认一次 |
| 雨 | D1 雨夜收留 → D2 廊下 → 结局闭环 | 雨把「回来的路」一次次洗净 |
| 水壶 | 手记得怎么握，脑子却空白 | 身体比记忆更早认得这里 |
| 「不能弄丢这里」 | 本子上被反复描粗的一行 | 被重写过很多轮的执念 |

## 1. 产品定义

### 1.1 一句话

> 你独居在河边一处荒了很久的农场，收留了一只会周期性遗忘的狐狸。十天，是她漂泊多年后的**最后一个轮回**：她记下你、忘了你、又在雾里重新认出你。而当雾散尽你才发现——**忘的从来不只是她，也是你；你们是彼此的锚。谁都好不了，但你们总能从空白里，重新把对方找回来。**

### 1.2 核心体验（仅三件事）

1. **被记住** — 名字、约定、日记、习惯写入存档  
2. **被忘记** — 中段陌生化，制造情感落差（并埋下「忘的也有我」的暗线）  
3. **被认回** — 终章不是「全部想起」，而是她**又一次忘光后仍照本子走回田边**；你笑着第 101 次告诉她你是谁——而她也点破：忘的不只是她，你们一直在互相打捞  

### 1.3 明确不做

- 星露谷式经营扩张（多作物 / 大地图 / 第二角色）  
- 35 日赛季密度  
- LLM 改写主线情节或自写长期记忆  
- 聊天框主动刷剧情（ambient 每日最多 1 条）  

### 1.4 对外 Pitch

> 《河可松》— 十日完整故事。与 AI 伙伴小狸一起种田、聊天、留下约定；她会忘记你，也会在雾里慢慢认出你。多结局。

## 2. 结构总览

### 2.1 三幕

```text
第1幕  留下（D1–D3）   相识 · 写入 · 建立「我们」
第2幕  雾起（D4–D7）   遗忘 · 选择 · 重新教 · 回响
第3幕  归来（D8–D10）  本子 · 前夜 · 觉醒终章
```

### 2.2 story_mode 映射

| 天数 | story_mode | 对 LLM / 记忆 |
|------|------------|---------------|
| D1–D3 | `prologue` / 日常 | 写入；可正常聊天 |
| D4–D5 | `stranger` | **关闭 episodic**；禁亲昵与具体回忆 |
| D6–D8 | `leak` | Top-3 citable；节点渗漏 |
| D9–D10 | `awaken` | 终章；可连贯认出 |

### 2.3 日程纪律

- **每天必须有主节点**（可 blocking 过天）  
- **每天至少 1 次个性化写入或读取**  
- **禁止空过日**（无节点、无回调、无选择）

## 4. 个性化定稿

### 4.1 五条必做槽位

| 槽位 / 数据 | 写入 | 读取 |
|-------------|------|------|
| `{player_name}` | D1 取名 | D4 禁用；D7 / D10 启用 |
| `{promise.summary}` | D3 节点结束强制写入 | D7 复述；碎片；D10 |
| `day_journal` | 每晚入睡 | D6 渗漏；D8 本子；**D10 蒙太奇** |
| `prefs`（节律/作物） | D2～D6 行为 | D6+ 开场 / hint |
| 高 salience 聊天或投喂 | D1～D5 | D6 渗漏 1 条 |

### 4.2 每日个性化 KPI

| 天 | 玩家应感到 |
|----|------------|
| D1 | 她叫得出我起的名字（或知道我要她怎么叫） |
| D2 | 雨天廊下是「我们的」第一段日常 |
| D3 | 我们有一句约定进了本子 |
| D4 | 她真的不认得我了（不是 bug） |
| D5 | 我的选择会改变故事 |
| D6 | 她漏出一句 **只有我档才有** 的旧事 |
| D7 | 她叫回我的名字 / 复述我们的约定 |
| D8 | 本子里有我们日子的痕迹 |
| D9 | 她预告「明天有重要的话」 |
| D10 | 蒙太奇里出现 **我的** 日记句 |

### 4.3 双档验收（个性化交付标准）

- 档 A：多聊天、傍晚上线、投喂零食、认真看节点  
- 档 B：几乎不聊天、只种田速过  

**必须不同：** D7 台词（名字/约定）、D10 蒙太奇至少 2 句 journal。  
**否则个性化未交付。**

### 4.4 AI 边界（不变）

- Plot 管发生什么 · Memory 管记得什么 · Persona/LLM 管怎么说  
- LLM **禁止** `memory_write`  
- D4–D5 stranger：OOC / 叫名 / 具体回忆 → 校验拦截  
- 事实锁：田况 / 天气 / 价格以 `GameState` 为准

## 6. 结局定稿

### 6.1 结局一览

| ID | 名称 | 触发倾向 |
|----|------|----------|
| `ending_normal` | 安顿 | 收留 + 正常推进至 D10；苦甜，把彼此当作要反复重新认识的人；枕边并排两个本子 |
| `ending_happy` | 共处 | 收留 + 聊天/陪伴达标；她好不全，但农场成了家；「你忘我提醒你、我忘你提醒我」 |
| `ending_true` | 最后一程 | 收留 + 约定兑现 + 恢复/碎片阈值；D10 收网「忘的也有我」，两个本子并排为下一轮留锚 |
| `ending_bad_early` | 放手 | **D5 赶走** → D6 **短终章**；她鞠躬道歉离开，我亲手斩断了那个把你们牵到一起的方向 |
| `ending_bad` | 雾中 | 收留但低互动 / 低恢复；没接住她、也没替你们留下那个锚，她像随时飘走 |

> **重要**：True/Happy **不是治愈**。永不痊愈是脊——**谁都好不了，包括「我」**。收束语落在「双向遗忘·互相打捞·为下一轮留锚」上，不写「她终于痊愈 / 永远记得你了」，也不引入第三个人物。

### 6.2 D10 觉醒（非全部想起）

- 触发日：**game_day == 10**（原 35 改为 10）  
- 开场：她**又忘光了今天**，照着本子重新走到田边、重新问「我该怎么称呼你」；这一次「我」**没有崩溃**，笑着第 101 次报出名字。  
- 结构沿用：碎片墙 → journal 蒙太奇 → 结局 VO / F10 变体（标题改为「最后一程 / 这一轮认回了你」）。  
- **D10 收网**：幕三点破「忘的从来不只是她，也是你；你们是彼此的锚」。  
- 结局尾声接**两个本子闭环**：True/Happy/Normal 把她的与我的本子并排、为下一轮留下重新找回彼此的路；Bad/BadEarly 没能留下锚 / 亲手斩断方向。  
- True：最长；Happy：中；Normal：短；Bad：最短或不进完整 F10  

### 6.3 判定输入（压缩到十日可积累）

- `w2_chose_expel`（D5）  
- `companionship_nights`（D7 夜坐）  
- `promise.fulfilled`  
- `affection` / `memory_recovery` / 碎片数  
- 聊天天数 `chat_days`  

具体阈值以实现时 `EndingDirector` 调参为准，**原则：十日能区分四结局，不要求刷满 35 日数值。**

## 10. 成功标准（完整游戏）

玩家不读文档应能：

1. D1→D10（或 Bad early）**通关并看到结局**  
2. D4 感到遗忘，不以为是 bug  
3. D5 选择有可见后果  
4. D7 或 D10 听到自己的名字或约定  
5. 双档 D10 蒙太奇明显不同  
6. 无 API 可完整通关；有 API 不破坏 stranger / 事实锁  
7. Web / Windows 各至少完整通关一轮无阻断 bug
