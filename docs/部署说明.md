## 1. 整体架构（先搞清楚东西在哪）

```
玩家浏览器
   │
   │ ① 打开 https://....tcloudbaseapp.com/hekesong/
   ▼
┌──────────────────────────────────────────┐
│  CloudBase「静态网站托管」                 │
│  文件：index.html / index.js / index.wasm│
│        / index.pck / 若干 png            │
│  来源：本地 E:\hekesong\build\web\        │
└──────────────┬───────────────────────────┘
               │ ② 游戏中与小狸对话时，POST /v1/chat
               ▼
┌──────────────────────────────────────────┐
│  CloudBase「云托管 CloudRun」              │
│  服务名：xiaoli-api（容器型，Python）      │
│  来源：E:\hekesong\cloudrun\xiaoli-api\   │
│  环境变量里存着 DEEPSEEK_API_KEY          │
└──────────────┬───────────────────────────┘
               │ ③ HTTPS 调用大模型
               ▼
        DeepSeek API（api.deepseek.com）
        跑在 DeepSeek 自己的服务器上
```

**一句话**：游戏画面在腾讯云静态托管，小狸的"嘴"（代理服务）在腾讯云云托管，小狸的"脑子"（大模型）在 DeepSeek。三处拼起来才有完整体验。

**玩家数据在哪**：存档只存在**玩家自己浏览器的 IndexedDB** 里（换设备 / 清缓存就没），对话记录**不保存**，后端不写数据库。所以你没有用户数据合规压力，但也做不了跨设备读档。

## 3. 日常更新（真正会反复做的事）

### 3.1 改了游戏 → 重新部署前端

#### 方式 A：一条龙脚本（最简单）

**双击 `E:\hekesong\deploy_frontend.bat`** —— 它会自动完成"Godot 导出 → 清垃圾文件 → 上传到云端"三步。
跑完按 Ctrl+Shift+R 强刷验收即可。

> 前提：已装好 tcb CLI 并登录（见 §5）。只想导出不上传就用 `deploy_web.bat`。

#### 方式 B：命令行分步（想看清楚每步在做什么）

**第 1 步：导出**

```bat
"E:\Godot_v4.7-stable_win64.exe\Godot_v4.7-stable_win64_console.exe" --headless --path E:\hekesong --export-release "Web" E:\hekesong\build\web\index.html
```

> ⚠️ **要用 PowerShell 或 cmd 执行，不要用 Git Bash** —— Bash 沙箱会拦掉 Godot 写临时文件导致导出失败。

**第 2 步：清掉垃圾文件**

导出目录会混入 `*.import`（Godot 编辑器扫描产生的垃圾），**不要上传**：

```bat
del /q /s E:\hekesong\build\web\*.import
```

（`deploy_web.bat` 已经自动做了这步）

**第 3 步：上传**

```bat
tcb hosting deploy E:\hekesong\build\web hekesong -e goldfish-d4g2xlhzl229a1f53 --ignore "**/*.import"
```

**第 4 步：验收**

浏览器打开 `https://goldfish-d4g2xlhzl229a1f53-1457975289.tcloudbaseapp.com/hekesong/`，
**按 Ctrl+Shift+R 强制刷新**（否则很可能看到旧版本，见 §4.2）。

#### 方式 C：纯控制台（不想装命令行时）

1. 打开 `https://console.cloud.tencent.com/tcb` → 进 `goldfish` 环境
2. 左侧菜单 → **静态网站托管**
3. 点 **「上传文件」/「文件管理」**
4. 把 `E:\hekesong\build\web\` 里的文件（**排除 `.import`**）全部上传到 `hekesong` 目录，覆盖同名文件
5. 等 1~2 分钟 CDN 生效，强刷验收

---

### 3.2 改了后端 → 重新部署云托管

**第 1 步：同步代码**（最容易忘的一步！）

```bat
copy /Y E:\hekesong\tools\local_llm_server.py E:\hekesong\cloudrun\xiaoli-api\tools\
copy /Y E:\hekesong\config\*.json E:\hekesong\cloudrun\xiaoli-api\config\
```

> 云托管是**从 `cloudrun/xiaoli-api/` 这个目录打包**的，不是从 `tools/` 直接打包。改了源码不同步过去 = 白改。

**第 2 步：部署**

双击 `E:\hekesong\deploy_cloudrun.bat`，或手动：

```bat
cd /d E:\hekesong\cloudrun\xiaoli-api
tcb cloudrun deploy -e goldfish-d4g2xlhzl229a1f53 -s xiaoli-api --source . --port 8080 --open-access-types PUBLIC --min-num 0 --max-num 5
```

> 说明：`--min-num 0` 表示没人访问时不保留实例，**不烧资源包**（首次访问会有 10~20 秒冷启动）。想秒回就设 1，但会持续扣额度。

**第 3 步：等构建**

容器型服务要拉镜像 + 构建，通常 3~8 分钟。用下面命令查状态：

```bat
tcb cloudrun detail -e goldfish-d4g2xlhzl229a1f53 -s xiaoli-api
```

**第 4 步：验证**

浏览器直接打开 `https://xiaoli-api-288258-10-1457975289.sh.run.tcloudbase.com/health`，
正常会返回类似 `{"status":"ok","mode":"llm","has_api_key":true}`。

---

### 3.3 换 Key / 改实例数 → 不用重新部署

**改环境变量（换 DeepSeek Key）：**

1. 控制台 → `goldfish` 环境 → **云托管** → 点 `xiaoli-api`
2. 找 **「服务配置」/「环境变量」**
3. 改 `DEEPSEEK_API_KEY` 的值 → 保存
4. 服务会自动重启，不用重新部署

> 后端识别的环境变量名（任选其一即可）：
> - `DEEPSEEK_API_KEY` / `OPENAI_API_KEY` / `LLM_API_KEY`
> - `LLM_BASE_URL`（可选，换兼容服务商时填）
> - `LLM_MODEL`（可选，默认 `deepseek-chat`）
> - `HOST` / `PORT`（容器已设好 `0.0.0.0` / `8080`，别改）

**改实例数（省钱）：**

控制台 → 云托管 → `xiaoli-api` → 编辑配置 → **最小实例数改成 0** → 保存。

## 4. 故障排查表（照症状查）

### 4.1 网页里中文全是方块（豆腐块）

**原因**：Web 浏览器里**没有系统字体**。Godot 默认字体不含中文字形；代码里如果用了 `SystemFont`（指定微软雅黑/PingFang），在网页里也取不到。

**已修好的配置**（不要再动，除非要换字体）：

1. `project.godot` 末尾有：
   ```
   [gui]
   theme/default="res://theme_default.tres"
   ```
2. `theme_default.tres` 用 `ext_resource` 引用 `assets/fonts/` 下的 **.ttf 源文件**。
3. `scripts/autoload/ui_theme.gd` 在代码层加载主字体（站酷快乐体），缺失时回退 `zpix.ttf`。

**换字体时三个致命坑（务必避开）**：

| 坑 | 说明 |
|---|---|
| ❌ 引用 `.godot/imported/*.fontdata` | 这个目录**不会被打包进 pck**，浏览器里路径不存在 → 字体失效 |
| ❌ 手写 `FontData` 子资源塞进 Theme | 导出时整个主题可能解析失败，默认字体静默失效 |
| ❌ 依赖 `allow_system_fallback` | Web 环境没有系统字体可回退，只会显示方块 |

**正确做法**：Theme 里一律写
```
[ext_resource type="FontFile" path="res://assets/fonts/你的字体.ttf" id="1_f"]
[resource]
default_font = ExtResource("1_f")
```

**如果只有标题正常、按钮是方块**：说明标题走了代码 `load()`，但全局主题没生效。检查 `project.godot` 的 `theme/default` 是否指向正确的 `.tres`，以及那些控件上有没有单独的 `theme_override_fonts`（个别控件覆盖会盖掉全局主题）。

**当前字体**主字体 `ZCOOLKuaiLe-Regular.ttf`（站酷快乐体），回退 `zpix.ttf`。想换就放进 `assets/fonts/` 并改 `ui_theme.gd` 的 `PRIMARY_FONT_CANDIDATES`。

---

### 4.2 改了游戏但线上还是旧版本

**原因**：`index.pck` / `index.wasm` 文件名固定，覆盖上传后**浏览器缓存 + CloudBase CDN** 可能还在喂旧包。

**排查顺序**：
1. **先 Ctrl+Shift+R 强制刷新**（80% 的情况这一步就解决）
2. 用无痕窗口打开
3. 传到带版本号的目录，例如：
   ```bat
   tcb hosting deploy E:\hekesong\build\web hekesong/v7 -e goldfish-d4g2xlhzl229a1f53 --ignore "**/*.import"
   ```
   然后访问 `.../hekesong/v7/`（全新路径，零缓存）
4. 控制台 → 静态托管 → 看 `index.pck` 的**更新时间和大小**是否和你本地一致

---

### 4.3 小狸不说话 / 后端 503 `SERVICE_FORBIDDEN "server is isolated"`

**原因**：**体验版免费资源包用完了**，腾讯云把云托管服务隔离（暂停）。
`MinNum=1`（常驻实例）即使没人玩也 24 小时扣资源点，体验版大约撑 3~7 天。

**解决**：
1. 控制台 → `goldfish` → 云托管 → `xiaoli-api`，确认显示"已隔离"
2. 找 **「套餐管理」/「资源包」/「计费概览」**，续额度或升正式版
3. 恢复后**立刻把最小实例数改成 0**，防止再次被隔离
4. 服务恢复会自动重启，**不用重新部署**

**验证**：打开 `/health` 能返回 `{"status":"ok"}` 就是恢复了。

> 注意：静态托管（游戏画面）通常不受影响，被隔离的只是云托管。所以会出现"游戏能打开，但小狸不说话"。

---

### 4.4 后端偶发 503 `LLM returned internal metadata instead of dialogue`

**原因**：DeepSeek 偶尔返回了非 JSON 文本，被后端的响应校验拦下。
**影响**：不致命。游戏端有本地兜底回复，小狸仍会说话（只是偶尔用预设句）。
**处理**：再说一句即可，或连续重试。

---

### 4.5 首次部署后端报"云托管资源未开通"

**原因**：环境建好后云托管要**手动开通一次**。
**解决**：控制台 → 云托管 → 点「开通」→ 回来重新执行部署命令。

---

### 4.6 导出失败

| 症状 | 处理 |
|---|---|
| 在 Git Bash 里导出被沙箱拦 | 改用 **PowerShell 或 cmd** 执行 |
| 提示找不到导出模板 | Godot 编辑器 → 编辑器 → 管理导出模板 → 下载安装 |

## 5. 命令行工具安装（只需做一次）

一键脚本和 Agent 代跑都依赖 CloudBase CLI（命令名 `tcb`）。没有它，只能在控制台手动上传。

### 5.1 装 Node.js（没有 `npm` 时）

打开 https://nodejs.org 安装 LTS。装完**新开**一个 PowerShell 或 cmd，执行 `npm -v` 有版本号即可。

### 5.2 装 `tcb`

必须用 **PowerShell 或 cmd**，不要用 Git Bash。

```bat
npm i -g @cloudbase/cli
tcb --version
```

Windows 上可执行文件一般在 `%APPDATA%\npm\tcb.cmd`。若提示找不到命令，关掉终端再开一次，或把 `%APPDATA%\npm` 加进 PATH。

本机曾验证过：`@cloudbase/cli` **3.8.6** 可正常跑 `tcb --version`。

### 5.3 登录腾讯云（必须人点浏览器）

```bat
tcb login
```

会弹出腾讯云授权页，用有 `goldfish` 环境权限的账号登录。Agent **不能**代替这一步。登录成功后再执行 `tcb --version` 或 `tcb cloudrun list -e goldfish-d4g2xlhzl229a1f53` 确认没报未登录。

### 5.4 让 Agent 一键部署（登录之后）

对 Cursor 说其中一句即可：

- **「部署前端」**：跑 `deploy_frontend.bat`（Godot 导出 Web → 清 `.import` → 上传 `/hekesong/`）
- **「部署后端」**：跑 `deploy_cloudrun.bat`（同步 `tools/local_llm_server.py` 与 `config/*.json` → 部署 `xiaoli-api`）
- **「前后端都部署」**：先前端后后端

前提：

1. 已 `tcb login`
2. 部署前端时**先关掉**正在打开本项目的 Godot 编辑器
3. Godot 路径仍是 `E:\Godot_v4.7-stable_win64.exe\Godot_v4.7-stable_win64_console.exe`（换电脑要改 bat 里的 `GODOT`）

自己双击上述 bat 效果相同。只想导出不上传用 `deploy_web.bat`。

**常用命令速查**：

```bat
:: 登录
tcb login

:: 上传前端（覆盖 /hekesong/）
tcb hosting deploy E:\hekesong\build\web hekesong -e goldfish-d4g2xlhzl229a1f53 --ignore "**/*.import"

:: 部署后端
cd /d E:\hekesong\cloudrun\xiaoli-api
tcb cloudrun deploy -e goldfish-d4g2xlhzl229a1f53 -s xiaoli-api --source . --port 8080 --open-access-types PUBLIC --min-num 0 --max-num 5

:: 看后端服务列表
tcb cloudrun list -e goldfish-d4g2xlhzl229a1f53

:: 看后端详情（状态、域名）
tcb cloudrun detail -e goldfish-d4g2xlhzl229a1f53 -s xiaoli-api

:: 看后端日志
tcb cloudrun logs -e goldfish-d4g2xlhzl229a1f53 -s xiaoli-api

:: 看静态托管文件列表
tcb hosting list hekesong -e goldfish-d4g2xlhzl229a1f53
```

## 6. 费用与省钱

| 项目 | 计费方 | 大概成本 |
|---|---|---|
| 静态托管（游戏文件） | 腾讯云资源点 | 体验版免费额度内，很低 |
| 云托管 CloudRun | 腾讯云资源点 | **主要开销**。`MinNum=1` 常驻会持续扣 |
| DeepSeek API | DeepSeek 按 token | 很便宜，小范围体验几毛到几块 |

**省钱的三个动作**：
1. 平时把 **最小实例数设成 0**（有人玩自动拉起，代价是首次冷启动 10~20 秒）
2. 一段时间不给人玩，直接在控制台**删掉 `xiaoli-api` 服务**，需要时再部署（命令在 §3.2）
3. 定期去 `platform.deepseek.com` 看用量，别让 Key 被异常盗刷

> ⚠️ **安全提醒**：你当前那个 DeepSeek Key（`sk-f123...`）曾经在聊天记录里出现过。强烈建议去 DeepSeek 后台**重新生成一个**，然后在控制台环境变量里替换掉。替换不用重新部署。
