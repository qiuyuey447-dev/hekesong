## 序 · 空荡的家园

有些告别，并不是终点。它们只是换了一种样子，循着心底那点温柔的熟悉感，重新找到了回家的路。

玩家曾有一只陪伴多年的 furry。它老去、离去。玩家收起它的窝，把 grief 藏进日常——路过它爱打滚的草皮时，仍会下意识想喊它的名字。

> 它离开了吗？也许，只是你看不见它了。

---

## 第一章 · 不速之客

小狸出现在门边：眼神清澈，却茫然，不记得从哪来。记忆像被截断，只循着内心指引，走了很远，停在你的门前。

## 第二章 · 似曾相识

看见萝卜田与旧屋，小狸感到安心——「这里就是该留下的地方」。她请求留下帮工、陪伴。玩家望向她，有说不清的熟悉，点头：「那就……留在这里吧。」

## 第三章 · 两个人的家园

一起浇水、看天气、晒被、雨夜廊下听雨。小狸有时会突然断片。玩家耐心重新介绍：「没关系，忘了就重来。我们有的是时间。」

## 第四章 · 真相

**它一直都是它**——玩家逝去伙伴的灵魂，依附在新机体上归来；记忆断裂，但情感从未真正断开。

## 从未离开

想告诉失去伙伴的人：它们换了一种样子回来。七日田居，是重逢之地。

## 背景设定 × 玩法机制

| 概念 | 说明 |
|------|------|
| **记忆缺失 / 系统故障** | 叙事根因；支撑「七日记忆循环」 |
| **七日后记忆重置** | 不是 bug，是小狸装不下全部记忆 |
| **隐藏记忆层** | W2～W4 似曾相识的来源 |
| **五周目觉醒** | W5 拼齐记忆、认出玩家；七日法则解除 |
| **羁绊系统** | 羁绊越深，小狸越愿为你分担（浇水、提醒、陪伴） |
