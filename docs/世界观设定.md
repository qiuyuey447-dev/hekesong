# 《河可松》· 世界观与故事内核（权威定稿 v2）

> 本文是十日版剧情的**唯一权威 brief**。所有玩家可见文本（`config/story_nodes.json`、`scripts/autoload/ending_director.gd`、`scripts/world/demo_script.gd`）与测试断言（`tools/story_test_runner.gd`）均以本文为准。
>
> 定稿模型：**双向遗忘 · 她的学习为真 · 互相打捞。**
> 纯双人（我 + 小狸）· 永不痊愈 · 最后一个轮回。不引入第三个人物（无阿嬷 / 无病房 / 无逝去伙伴）。

---

## 〇、最重要的一条铁律（产品命根，不可违背）

**小狸的「记住你、学习你」必须是真的。** 她每一轮都真的失忆、真的从零把「这个具体的玩家」重新学一遍——名字、习惯、约定、聊过的话。**个性化 = 她忘光了，仍能一次次从头把你学回来。** 任何让她「其实一直记得、只是装忘」的写法都被禁止：那会让玩家追认这段关系是假的，直接摧毁个性化。

---

## 一、一句话内核

> **我们都会忘。可我们总能，从一片空白里，重新把对方找回来。**

深度不靠辞藻，靠结构：**第一天「你该怎么称呼你」是她（真的）忘了你、从头学你；第十天一模一样的问句，在真相揭开后变成——原来我们俩都在雾里，一遍遍互相打捞。** 同一句话，读两遍，意思整个翻过来。

---

## 二、双向遗忘模型（本次核心变更）

### 明线（前九天玩家所见）

- **小狸真的会周期性失忆。** 她整段整段清空，然后从零重新认这片田、重新学你。D4 把你当陌生人、D5 想离开，都是真的。
- **玩家在这十天里是「清醒」的一方**：教她浇水、一次次重新介绍自己、替她记着。**个性化关系就在这条明线里真实地建立**——她凭那点「模糊的方向」，总能重新摸回到你、重新记住你的名字与约定。

### 暗线（D10 揭示）

- **其实「我」也在这个循环里。** 这十天，不过是无数轮中的一轮。**我也会在轮与轮之间重置、忘光**——只是我一直以为自己是那个稳的、替她记着的锚。
- 玩家全程偶感的**「莫名眼熟她」「这片田我好像来过」**，不是她的错觉投射，**是「我」自己前几轮漏出来的记忆**。
- **她拼命回来，不靠偷偷记得**（她真的没记住）——靠的是那份被一次次重新学出来的羁绊，深到能穿过遗忘、变成本能，像「心里有个方向牵着她走回河可松」。**而「我」心里，也有同一个方向。**
- **结论：我们是彼此的锚，谁都不是稳的那个。** 爱不是谁记住谁，是两个都会忘的人，一轮轮从空白里重新找回对方。

### 永不痊愈

**谁都好不了。** 不存在「其中一个被治好」。这一点不因任何结局改变。

## 三、背景设定

### 地点 · 河可松

河边一处偏僻、安静的小农场。名字取意 **「河边，可以松一口气的地方」**——对漂泊的人而言，是能把东西放下、喘口气的落脚处。结尾回扣：我们俩漂了很多轮，找的都是一个「可松」、且能重新找回彼此的地方。

### 「我」

- 守着这片田，独居，少与外界往来；把日子过得很淡，因为淡的东西不会痛。
- **伤口（普遍、内敛）**：怕失去，所以不敢拥有、不敢许诺。
- **暗线真相**：我以为自己是替她记着的人，其实我也在一轮轮遗忘。玩家弧光 = 从「不敢拥有」→「明知都会忘，仍选择留下、留下能让彼此重新找到对方的锚」。

### 小狸

- 会周期性、整段清空记忆的狐狸，漂泊者。
- 每次醒来白纸一张，只凭心里一点模糊的方向，被牵回河可松，从零重新学这片田、学你。
- **她的个性化是真实的、可被玩家塑造的**：你怎么待她、告诉她什么、和她约定什么，都会真实沉淀进「她这一轮重新认识的你」。

### 遗忘成因：不解释

不说病、不说灵、不说任何设定。留白即深度：你无法知道所爱之人为何会忘、为何会走，只能决定在还认得的时候，怎么陪、留下什么。给「医学 / 灵魂」解释会把「人人都懂的痛」降格为「一个特殊案例」，反而变浅。

## 四、暗线的公平埋设（防「廉价反转」清单）

D10 揭示「我也在循环里」必须让玩家二周目回看时觉得「我早该发现」，而非凭空翻转。全程留可复查的暗线：

1. **D1**：我「莫名眼熟她」，眼熟到心里发紧——不是似曾相识那么轻。
2. **似曾相识的错位**：偶尔是「我」先一步知道田里的事、脱口说出连自己都惊讶的细节（不是只有她的手记得）。
3. **两个本子（最重）**：她写「不能弄丢这里」（醒来自我锚定）；**我也有一个本子，写满了她**——表面是「怕她走后我忘她」，D10 重读才懂，是「我怕自己下一轮重置后，连她都认不出」。
4. **系统 / 旁白的轻微口误**：偶尔分不清「是谁在照顾谁」「是谁先来的这片田」。
5. **时间感的破绽**：我对「这片田荒了多久、我来了多久」始终说不清。

> 暗线要轻、要可否认，不点破；直到 D10 才收网。

---

## 五、深度五层（从浅到深）

1. **表面**：孤僻的人收留会失忆的狐狸，一起种田。温暖生活流——愿意读下去的糖衣。
2. **关系 · 互为镜子**：她怕忘了这里；我怕忘了她。同一个敌人，站在两头。**两个本子 = 实体化。** 玩家不是圣人，是同样有软肋的人。
3. **存在 · 人靠「被谁一次次重新找回」而存在**：她忘光仍能重新学回你，我忘光仍被那点方向牵回她。**记忆会碎，羁绊却能穿过遗忘。** 一字不点破，全靠「两个本子」「报名字」「重新学浇水」几个动作扛。
4. **普世 · 无解仍留下**：照见陪伴衰老 / 失智 / 终将离开的至亲。内核不是「等谁好起来」，而是**明知都会忘，仍甘愿一轮轮重新认识彼此**；不求治愈，求「每一次都能重新找回对方」。
5. **元层（游戏专属，不写进台词）**：小狸是 AI 伙伴，「失忆 / 重置」正是 AI 陪伴最真实的焦虑——它会不会哪天把你忘了、你会不会也终将忘了它。存档、每日、「记起的片段」系统在 D10 后被追认为**字面真实**：玩法机制 = 主题本体。

---

## 六、核心母题

- **本子（最重）**：D8 完成变义——她的本子「不能弄丢这里」（醒来自锚）↔ 发现「我」也有一本、写满了她。**「原来你也怕忘」这句，D10 后双向成立**，并暗示「我」也是忘的那一个。
- **「不能弄丢这里」**：她本子上被反复描黑、跨越多轮的一行。
- **报名字 / 「我该怎么称呼你」**：D1 她从零学你 ↔ D10 真相揭开后，成为「两个都会忘的人互相打捞」的信物。首尾同句反转。
- **「模糊的方向」**：牵她回河可松的本能；D10 揭示「我」心里也有同一个方向。
- **水壶 / 浇水的手、雨、树洞、萝卜田**：落脚、安顿、约定与「身体先于记忆」的载体。

## 七、十天节奏（重场 5 个：D1 / D4 / D7 / D8 / D10）

| 天 | 结点 | 内容落点 |
|---|---|---|
| D1 | 登门 · 又一次归来 | 她（真）从零登门；我「莫名眼熟她」到心里发紧（暗线①）。收留。她问「该怎么称呼你」。 |
| D2 | 雨 · 廊下 | 安稳低音。递烤红薯。我起念「真想把此刻记下来」（埋我的本子 = 暗线③）。 |
| D3 | 约定 | 「等萝卜长好，一起看」。她写进本子。我发现自己已很久不敢许诺。 |
| **D4** | **陌生化（第一记重拳）** | 她（真的）把我当陌生人。我尝到「被忘记」，也第一次隐隐怕：这感觉我好像也经历过（暗线）。 |
| D5 | 留 / 放 | 她抱包袱要走；留下 = 选择继续痛。玩家主动付代价（保能动性）。 |
| D6 | 似曾相识（错位） | 她的手记得田；偶有一次是**我**先一步说出细节，自己都惊（暗线②）。 |
| **D7** | **认回（情感最高点）** | 她从零重新学，终于清醒叫出我的名字、念出约定（个性化兑现）。**这一夜「我」落笔，第一次写下她。** |
| **D8** | **两个本子（母题变义）** | 翻她的本子（跨多轮 /「不能弄丢这里」）→ 她发现「我」也有一本、全是她。「原来你也怕忘。」（暗线③收半） |
| D9 | 前夜 | 「明天想把一切告诉你」。这样清醒的明天，或许是最后一个。 |
| **D10** | **觉醒 / 揭示 / 结局** | 她照本子又问「该怎么称呼你」。这次我没崩溃。**真相收网：原来我也在循环里，我们是彼此的锚。** 我在短暂的清醒里做出选择（夺回能动性）。 |

## 八、五个结局（分野 = 「有没有替彼此留下能重新找回对方的锚 + 敢不敢留下」）

| 结局 | 落点一句 |
|---|---|
| **True** | 我们都会忘。可我在这一轮认清了：只要把彼此的锚留下，下一轮再空白，也总能重新找回来。 |
| **Happy** | 我没全看穿这循环，只安心活在她一次次重新学我的温柔里——这也是一种圆满。 |
| **Normal** | 「明天我们大概又糊涂了。可今天，我们认得彼此。」——够了。 |
| **Bad** | 雾又漫上来，这一轮，我没接住她，也没替我们留下那个锚。 |
| **BadEarly** | 我太早把她推开——亲手切断了那个、一轮轮把我们重新牵到一起的方向。 |

> True/Happy 不是「治愈」，是「在会忘的前提下，仍为下一次重逢留了路 / 好好爱了这一程」；Bad/BadEarly 是「这一轮没留住、或亲手斩断了循环」。**谁都好不了，这一点不因结局改变。**
