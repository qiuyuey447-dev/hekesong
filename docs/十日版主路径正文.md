# 十日版 · 主路径正文（现行稿 · 模型A：双向遗忘）

**叙事内核**：双向遗忘 · 她的学习为真 · 永不痊愈 · 最后一个轮回。详见 `docs/世界观设定.md`（权威 v2）。
**用法**：直接改本文件正文 → 告诉我「改 D3 / 改 D7 true」等，我回填对应文件。
**占位**：`%s` = 小狸名（位置参数）· `{player_name}` `{promise.summary}` `{notebook_excerpt}`（她的本子）`{my_notebook_excerpt}`（我的本子·专属渗透）`{companion_name}` 运行时填槽。
**渲染约束**：`templates` 与 `route_by_suffix` 每条至多一个 `%s`，且勿在「仅一个 %s」的句子里写「这片」（会被当作 crop 特例）。

**前期基调（D1–D3）**：贫嘴，带点小腹黑——占廊下干处还说是给你留的、蹭吃的先夸再要、把苗拨歪赖说是跟你学的、被戳穿就拿「我记性不好」当免死金牌耍赖，占完自己先心虚地笑一下。玩笑短、冷、一句就收。**边界**：腹黑只到「占小便宜、嘴上不饶人、装可怜」，不算计玩家、不刻薄；**绝不能演成「其实都记得、只是装忘」**（违反世界观 §0），她是真的会忘。D4 起玩笑全停——玩笑消失本身就是刀，不用旁白点破。
落地位置：`config/xiaoli_persona.json`（人设卡，双端同步）· `scripts/autoload/npc_bridge.gd::_get_phase_tone()`（D1–D3 覆盖关系阶段的拘谨调）· 本文 D1–D3 正文 · `npc_fallback.gd` tier 0 闲聊。

## D1 · 登门 · `P_N01`

**主节点**（正常开局播这个，不叠清晨）

```
暮色里，田埂尽头站着一个人——{小狸}。鞋上的泥还没干，尾巴尖也沾着。

你停了一停。像见过。想不起来是哪儿。

她先看田，再看自己的鞋：「能在这儿帮工吗。浇水、拔草、跑腿，我都行。」顿了顿，「给口饭，有地方睡就成。——比如那个树洞。看着就没人要。」

你说树洞空着，她要是不嫌。她立刻点头，点完才想起来补一句：「我不挑的。」

她拍了两下鞋上的泥，没拍干净，倒把廊沿蹭花了一道。自己先笑了一下，又赶紧收住：「那……我该怎么称呼你？」
```

> 埋点（暗线①）：我「像见过」，想不起来是哪儿。她的笑是真的——后面才能收。
> 腹黑第一手：她进门前就把住处看好了，嘴上还说「我不挑」。

**取名弹窗**

- 正文：`那……我该怎么称呼你？叫起来别太绕口就行。`
- 确认后对话：`……{名字}。好。我先念三遍。`

**当天对话**：`泥我先拍拍。田我可以浇。——你这垄，是不是走歪了？`

## D2 · 雨天廊下（强制雨）· `P_N02`

```
雨是后半夜下的，天亮了也没停。

{小狸} 占了廊下最干的那一块。见你来，她往里挪了挪，把干的让给你：「给你留的。」——她挪开的那块，本来就是她自己先占的。

「有屋顶真好。」她把尾巴从水洼里拎出来，甩了甩，「以前下雨，我只能跟树商量。」

灶上剩着半块烤红薯。你递给她。她咬一口，眼睛亮了：「这个，比树好说话。」又往灶上瞟了一眼，「……还有吗。没有也行，我随口问问。」

雨打廊檐。她吃得很慢，最后一小口含着不咽，说这样显得还有。你没催。
```

> 三档差异：warm 掰一半但大的留自己「我个子小，饿得快」；mid 你说不饿，她把推回来那块又拿了回去，动作挺快；cold 收起玩笑（关系冷的对照组，不要加料）。

**第二页** `P_N02_b`

```
雨还没停。她把红薯渣拍掉，把尾巴从廊柱上挪开。

「这块干的，我占过。」她说，「明天……还让你。」停了一停，「让一半。」

廊下多了一点她的味道。你没接话。
```

**邀请**：`廊下不漏，红薯还热。你不来我可就都吃了。`

## D3 · 约定 · `P_N11`

**第一页** `P_N03`（跟浇）

```
黄昏，萝卜田被染成金红。{小狸} 跟在你身后浇水，走两步学你一次，学着学着自己先笑：「你这垄走得歪。我跟着歪。」

她把壶换了只手，补一句：「以后苗长得不齐，可就是你教的。跟我没关系。」
```

**第二页** `P_N11`

```
萝卜苗齐了。傍晚，{小狸} 蹲在田边，把一棵苗拨正，又拨歪，又拨正。

「等它们长好了……我们一起来看看，好不好？」她说完，自己先捂了一下嘴，「不是要你发誓。就是……我记性不太行。」

「『记性不好』这话挺好用的。」她掰着指头数，「今天的水我忘浇了——记性不好。红薯我多吃了半块——记性不好。」数到第三根，她自己卡住了，把手放下，「……这一句我不想拿它赖掉。」

她翻开那个卷了边的本子，一笔一画写下这句，念给你听：「写进本子了。哪天我要是问『这苗谁种的』，你拿这个砸我。」

你点了点头。嘴里没接话。
```

> 须含「本子」。玩笑底下是她真的会忘。
> **全剧最重的一处铺垫**：前期她拿「我记性不好」当免死金牌到处耍赖，玩家跟着笑；唯独这一句她不肯赖掉。D4 她忘的偏偏就是这一句——同一个梗，隔一天变成刀。改 D3 时别把这段删了。

## D4 · 陌生化 · `P_N05` + 清晨 telegraph

**清晨（必注入）** `t10_d4_telegraph`

```
清晨风很凉。廊下那块她坐过的地是干的。她站在田埂上望着你，看了很久，像不认得。你的名字，她弄丢了。
```

**主节点**

```
你照常走到田边。{小狸} 往后退了半步，水壶还握着。

「你是谁？」她声音发紧，随即又客客气气地补上，「……你是这儿的主人吧？我不是坏人，就是路过，想讨口饭——」

跟第一天一模一样的一句话。她自己不知道。

田还是那方田。苗还在长。廊下那块干地还在。红薯的事，你没提。你只把名字，又报了一遍。

她跟着念，念得很生。
```

> 须含「你是谁」；清晨须含「弄丢」。玩笑全部停掉。
> D1 回声：她重复第一天的讨饭请求。红薯（共有记忆）不提，名字（可以重给的东西）要给——「再告诉你一遍」的母题在这里立起来，D5 选项与 D10 收尾各回声一次。

**第二页** `P_N05_b`

```
你去浇水。她跟上来。壶还握着。垄还认得。人却不认得。

她浇得很稳。浇完，站在你旁边，像在等一句介绍。

你把名字又说了一遍，带她认了认地方——树洞在哪，水沟在哪，廊下哪块不漏雨。她将信将疑地点头。

那一整天，你心里都堵得慌。
```

**第一页** `P_N06_a`（发现本子）

```
你在树洞边找到了 {小狸} 的本子。纸页发旧，角上沾着泥。有一页只写了半句，后面空着。
```

**第二页** `P_N06_b`（对不上的日期）

```

最上面那行被描过很多遍——「不能弄丢这里」。墨渍叠着墨渍，像怕哪天连这一句也淡了。
```

> D5 只给情感（她怕弄丢这里 → 你留不留她）。「日期对不上 / 不止十天的量」是 D8 两个本子的信息，不在这里提前抖。

**第三页** `P_N06p`（抉择）

```
她还是往水沟那边走。脚迈出去，才茫然停住，像忘了水沟是干什么的。

{小狸} 攥着衣角，看你。没笑，也没拍鞋上的泥。

她在等一句能让她留下的话。你要是不说，她会走。
```

| 键 | 文案 |
|----|------|
| `w2_keep` | 留下她，再告诉她一遍 |
| `w2_expel` | 让她走 |
| 确认标题 | 真的要让她走吗？ |
| 确认正文 | 她会把活干完，把手套叠好，沿田埂走出去。说出去的话，收不回来。你确定吗？ |

**赶走短终章 D6** `BE_N07`

```
你说了让她走的话。

傍晚，{小狸} 仍把该浇的田一垄垄浇完。水壶搁回廊下，还冒着热气。手套叠好，放回树洞原处。柜角那只她从未用过的碗，也推了回去。

「走之前把活干完。」她冲你点了点头，没再笑，「谢谢你收留过我。」

她沿着田埂往外走。泥还是来时那层泥。这一回，她没有回头。

```

```
「奇怪……这块田我好像浇过。手一抬，就知道往哪儿走。」

她把水壶放下，没再问。
```

### true（最后一程）· 牙印

```
{小狸} 蹲在田边，指尖抚过萝卜叶。忽然，她摸到水壶柄上一道浅痕——像牙印。

她把壶翻过来看了看。「这块田，是你教我浇的第一片。对不对。」

「日子想不起来。」她把壶抱紧，「手记得。它比我早认得这里。」

她抬起另一只手，数了个数，数到一半又放下。没说数的是什么。
```

### happy（共处）· 她的碗

```
廊下多了一只碗。是 {小狸} 自己搁的，挨着你平常用的那只。

她把水壶往肩上一挎，熟得不像才学会：「有屋顶，有田，有你。这地方，我好像来过很多回。」

她当玩笑说的。碗沿还温着。
```

### bad（雾中）· 空土垄

```
{小狸} 浇完你的田，又走到田埂外那条没种东西的土垄上，把剩下的水慢慢浇下去。

「……你是这儿的主人吧。」她隔着一段距离看你，「田我看好。别的，你不用跟我讲太多。」

那条空土垄湿了一截。
```

**第二页** `*_N02p_b`（手还记得）

| 路线 | 正文要点 |
|------|----------|
| default | 她又绕回刚才那垄，写下一行：「这块，浇过。」**接着你脱口说出「底下有块石头，别硌着壶」——你不记得自己什么时候刨到过它。** |
| true | 傍晚数手指，数到四停住。「还剩几天。」**你脱口说「牙印是你自己咬的」，两个人都愣住。** 牙印朝外。 |
| happy | 洗了那只碗，搁回原处。「明天还在这儿。碗也是。」 |

## D9 · 前夜 · `*_N20c`

### default · 把壶灌满搁回原处

「明天，我想跟你说件事。」「……谢谢你，一直没赶我走。」今晚先歇着。明天见。

> 「谢谢你，一直没赶我走」四条路线除 bad 外都要有——D5 留她那一下，在这里收。

## D10 · 觉醒 / 收网 · `awakening`

**开场**（不要「请问」「第五周」）

```
第十天了。清晨，她照着本子，又一次走到田边，仰头问你：「你好……我该怎么称呼你？」

你报了自己的名字。像已经报过很多次。
```

**幕三 · True**（须含「不只是我」或「你也会忘」+「好不了」+「找回来」）

```
「这些田、这些字，是你一次次替我守下来的。可是啊……」她顿了顿，头一回没有回避你的眼睛，「你有没有发现——忘的，从来不只是我。」

「你也会忘。轮到你空成一片的时候，是我，一次次回来，把你重新认出来、重新告诉你：你是谁，这片田是你的，我们说好过什么。」

「我们谁都好不了。可这么多轮了，我们总能，从一片空白里，重新把对方找回来。」

{player_name}，这一轮，换你也把我，牢牢记住了。
```

**幕三 · Happy**：廊下那只碗 + 田边那粒新种。「这里是我的家——哪怕每天醒来，我都要重新认一次。」

**幕三 · Normal**：还温着的壶推到你手边。「今天，我认得 {player_name}——这就够了。」

**幕三 · Bad**：那只手套还在行李边。「对不起……我又把最要紧的，弄丢了。」
