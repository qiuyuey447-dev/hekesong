# 《河可松》十日版 · F5 手测清单

**用途**：对着编辑器 / 导出包勾验收。自动化烟雾见 `tools/story_test_runner.gd`。  
**启动**：Godot 打开项目 → F5；或标题「新游戏」。

---

## A. 收留主线（约 25–40 分钟）

| # | 天 | 必看 | 通过标准 |
|---|----|------|----------|
| A1 | D1 | 登门节点 → 取名 | 能起名；HUD 为「第 1/10 天」 |
| A2 | D2 | 雨天廊下 | **必为雨天**；廊下日常感 |
| A3 | D3 | 约定 | 她把约定写进本子；之后聊天/节点能复述 |
| A4 | D4 | 陌生化 + 清晨 telegraph | 有「不是存档坏了」类提示；她像不认识你 |
| A5 | D5 | 抉择 | 选「收留她，再教一遍」 |
| A6 | D6 | 似曾相识 | 有渗漏/déjà vu，不要求再下雨 |
| A7 | D7 | 叫名+约定 + 夜选 | **必出节点**；叫得出你的名；夜选「陪坐/回屋」有回应 |
| A8 | D8 | 本子 | 页里能看到日子痕迹（非空壳） |
| A9 | D9 | 前夜 | 预告「明天有重要的话」 |
| A10 | D10 | 觉醒 | 无「第五周」；蒙太奇里有你日记/亮点；能进结局 |

---

## B. 赶走短终章（约 10 分钟）

| # | 步骤 | 通过标准 |
|---|------|----------|
| B1 | 新游戏速推到 D5 | 日历正常 |
| B2 | 选「让她离开」→ 确认 | 进入放手线 |
| B3 | D5 夜或 D6 `BE_N07` | 短终章，不必拖到 D10 |
| B4 | 结局收束 | `story_complete`；无法再当正常十日推进 |

---

## C. 双档差异（个性化交付）

| 档 | 玩法 | D7 | D10 |
|----|------|----|-----|
| **A** | 取名、多聊、投喂、认真看节点、D7 陪坐 | 有名字 + 约定句 | 蒙太奇 ≥2 句像你自己的日子 |
| **B** | 不取名或乱点、几乎不聊、只过节点 | 不叫「阿松」式专名 / 台词不同 | 蒙太奇与 A 明显不同或走 fallback |

**必须不同**：D7 台词、D10 蒙太奇。否则个性化未交付。

---

## D. 回归抽检

- [ ] HUD / 标题存档提示无「周目」「第五周」
- [ ] 无 API（fallback）也能从 D1 走到结局
- [ ] D4–D5 聊天不亲昵、不乱叫名（有 API 时抽一句）
- [ ] 记忆面板「跳到终章日」→ D10 觉醒可开
