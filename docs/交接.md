## 1. 这是什么项目

Godot **4.7** 俯视像素农场 + AI 狐狸「小狸」。产品形态是 **10 日完整可通关**（不是 Demo、不是 35 日五周）。

一句话：玩家独居河边农场，收留会周期性失忆的小狸；这十天是她最后一个轮回。D10 揭晓忘的也不只是她。谁都好不了，但能从空白里把对方找回来。

核心体验只有三件事：被记住 → 被忘记 → 被认回。种田是生活质感，不是经营目标。

## 2. 铁律（违反即错）

叙事（定稿 §0.5，最高优先）：

1. **不引入第三个角色**（无阿嬷 / 病房 / 逝去伙伴）。
2. **小狸的失忆是真的**。严禁写成「其实一直记得、只是装忘」。
3. **双向遗忘**：玩家「我」在轮与轮之间也会忘；此真相 **D10 才收网**，此前只埋暗线。
4. **没有治愈、没有 New Game+ / 通关后再开一轮**。True/Happy 是「会忘的前提下仍留下锚」。
5. 对外只说「第几天」，不对玩家说「第几周 / 第五周 / 35 日」。
6. LLM **不改写主线、不自写长期记忆**。游戏状态是事实，LLM 只负责怎么说。
7. **剧情搭话须与 LLM 联调、统一口径**：凡小狸主动开口且与当日叙事相关（邀请、渗漏、闲聊、信纸后搭话、上线问候、玩家聊天等），**必须**走 LLM，且 payload 须带齐 `story_context` + `beat_context`（含 `variant_id` / `profile` / `invite_tone` / `invite_goal`）。信纸正文以 `story_nodes.json` 为准，LLM 只铺垫不念稿；**禁止**客户端另写与当日节点/亲密度档矛盾的固定台词。仅「追跑短句」等纯 UI 提示可本地兜底。改节点变体或 invite 时，**同步** `tools/local_llm_server.py` 与 `cloudrun/xiaoli-api/tools/local_llm_server.py`。完整 payload 规范见 **策划 §4.5.5**。

地图 / 范围（本迭代明确不做）：

- 不要第二张地图、室内、新作物种类、第二 NPC。
- 不要恢复中间那两垄「工作田」。可种的田 **只有最右边围栏里的三垄**。
- 不要对整张「草地」做 `set_cells_terrain_connect`（会把院子刷成米色）。这套 tileset **没有纯草 terrain**。
- 不要把相机 `limit_bottom` 设成 `yard.end.y + half.y`（会露出灰底）。
- 不要把走路锁死在小小的 `living_yard`（人会卡在聊天 UI 底下）。
- 不要 punch/erase **右边农田围栏**（`x >= 1448`）或 **河**（`x < 720`）。
- **不要把 F10 算进 True**。十日 True 只数 **F01–F05**（`count_ten_day_gate_fragments`）。觉醒收束时先冻结结局 id，再发 F10。

Git：

- **不要主动 commit / push**，除非用户明确说。
- 不要提交 `.godot/`、`build/`、`*.import`、`.env`、真实 API Key、`tools/_persona*.log`、`tools/_tmp_*`。
