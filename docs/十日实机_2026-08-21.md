## 玩家最触动的点

按「这一句只有这档才有 / 忘了又捞回来」排，不是系统句。

1. **D6 本子停在她自己写过的那一行**（新接线成立）  
   几乎每局都出现「聊过的字」页。最像人的是 **I3**：指尖停在「廊下手里那罐槐花蜜是我留给你的。」I5 停在「你记住，我叫路灯。」I1 停在槐秋的取名。玩家私货第一次真正印在 D6 信纸上。

2. **约定从本子里翻回来，人却对不上**  
   **I2 D6**：「萝卜那句还在。我在本子上写着呢……刚才说到哪了。」  
   **I2 D8**：「这话我写着，也记着。就是刚才一抬头，又差点忘了是跟谁说的。阿松，是你吧？」  
   这是十日卖点的实机例句：锚在、人糊。

3. **D4 真忘**  
   **I1 / I10**：「你说我们见过？对不起。我想不起来。」  
   **I5** 追问「我叫路灯」→ 只答雨和潮气，不接名字。这一刀还在。

4. **赶走短终章的安静**  
   **I9** 柜角那只碗、廊下凉了的壶。不必拖到 D10，收得住。

5. **True 并排两个本子**  
   **I10** 结局「不能弄丢这里」和「你写满了她的那一本」。I10 投喂也咬上了胡萝卜，D6 本子能翻到「你叫收集」。

6. **暗线猎手的身体记忆**  
   **I8**：「这田埂踩着挺熟，像哪回梦里踩过似的。」不问「以前来过」时，比念日记腰更像人。
